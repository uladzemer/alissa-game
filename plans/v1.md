# План v1 — «Приключения Алисы», играбельная версия

**Финишная черта:** владелец открывает ссылку GitHub Pages на телефоне (горизонтально) и на компьютере → проходит 5 уровней от опушки до замка → побеждает колдунью → видит сцену спасения принца. Консоль без ошибок, Playwright-проверка на 1280×720 и 844×390.

## Чек-лист

- [x] 1. Каркас: git init, Vite + TypeScript + Phaser 4, масштабирование под экран, сцены (Загрузка → Меню → Карта миров → Уровень → Финал)
- [x] 2. Алиса на временной графике: бег, прыжок, двойной прыжок, лазание по деревьям/лианам, коллизии с плитками
- [x] 3. Управление: клавиатура + экранные кнопки на тач-устройствах + просьба повернуть экран
- [x] 4. Бой: сердечки-выстрелы, щит, прыжок на врага, Кеша со спецатакой и перезарядкой; здоровье, неуязвимость после удара, флажки
- [x] 5. Враги: ёж, гриб, сова, лягушка, рыба, летучая мышь, собака; босс-колдунья
- [x] 6. Сбор: звёзды, клубнички, кристаллы; HUD; сохранение прогресса
- [x] 7. 5 уровней (текстовые карты), движущиеся/проваливающиеся платформы, вода (качели не делал — их роль играют движущиеся платформы)
- [x] 8. Графика через Codex: лист поз Алисы → Кеша, враги, предметы, плитки, фоны 5 миров, колдунья, принц, король; скрипт нарезки
- [x] 9. Синтезированные звуки; промпты для музыки в `docs/art-and-audio-prompts.md`
- [x] 10. Сюжетные экраны: начало с королём, финал со спасением
- [x] 11. Проверка Playwright (десктоп + телефон), прогон всех уровней
- [ ] 12. GitHub-репозиторий + Actions → Pages, ссылка владельцу

## Границы

- Всегда: Codex генерирует картинки только в изолированном worktree; `git add` только по путям.
- Спросить: всё, что меняет сюжет/героев/сложность; создание публичного репозитория (подтверждено в запуске v1).
- Никогда: жестокость (враги «добреют», а не погибают), внешние трекеры/реклама.

## Проверено (2026-09-25)
- Бот проходит уровень 1 целиком → экран «Кристалл найден» → карта.
- Вручную (телепорт + нажатия): лазание по дереву и подъём на крону, прыжки по кронам через яму (лес), катание на движущихся платформах (пещера) и плоту, падающие брёвна (речка), бой с колдуньей → кристалл → дверь → финал.
- Телефон 844×390 и 640×360 с касаниями: крестовина, прыжок вторым пальцем, выстрел, экран без чёрных полос; ошибок в консоли нет.
- Не проверено: полное прохождение уровней 2–5 живым игроком от начала до конца (бот слишком прост), реальный iPhone/Android.
