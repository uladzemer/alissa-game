# План v1 — «Приключения Алисы», играбельная версия

**Финишная черта:** владелец открывает ссылку GitHub Pages на телефоне (горизонтально) и на компьютере → проходит 5 уровней от опушки до замка → побеждает колдунью → видит сцену спасения принца. Консоль без ошибок, Playwright-проверка на 1280×720 и 844×390.

## Чек-лист

- [ ] 1. Каркас: git init, Vite + TypeScript + Phaser 4, масштабирование под экран, сцены (Загрузка → Меню → Карта миров → Уровень → Финал)
- [ ] 2. Алиса на временной графике: бег, прыжок, двойной прыжок, лазание по деревьям/лианам, коллизии с плитками
- [ ] 3. Управление: клавиатура + экранные кнопки на тач-устройствах + просьба повернуть экран
- [ ] 4. Бой: сердечки-выстрелы, щит, прыжок на врага, Кеша со спецатакой и перезарядкой; здоровье, неуязвимость после удара, флажки
- [ ] 5. Враги: ёж, гриб, сова, лягушка, рыба, летучая мышь, собака; босс-колдунья
- [ ] 6. Сбор: звёзды, клубнички, кристаллы; HUD; сохранение прогресса
- [ ] 7. 5 уровней (текстовые карты), движущиеся/проваливающиеся платформы, вода, качели
- [ ] 8. Графика через Codex: лист поз Алисы → Кеша, враги, предметы, плитки, фоны 5 миров, колдунья, принц, король; скрипт нарезки
- [ ] 9. Синтезированные звуки; промпты для музыки в `docs/art-and-audio-prompts.md`
- [ ] 10. Сюжетные экраны: начало с королём, финал со спасением
- [ ] 11. Проверка Playwright (десктоп + телефон), прогон всех уровней
- [ ] 12. GitHub-репозиторий + Actions → Pages, ссылка владельцу

## Границы

- Всегда: Codex генерирует картинки только в изолированном worktree; `git add` только по путям.
- Спросить: всё, что меняет сюжет/героев/сложность; создание публичного репозитория (подтверждено в запуске v1).
- Никогда: жестокость (враги «добреют», а не погибают), внешние трекеры/реклама.
