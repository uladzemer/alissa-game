# Приключения Алисы

Браузерный платформер для детей: девочка Алиса с попугаем Кешей проходит опушку, лес, речку и пещеру, собирает 5 кристаллов-ключей, расколдовывает злую колдунью и спасает принца.

**Играть:** https://uladzemer.github.io/alissa-game/ — на компьютере (стрелки, пробел, X, Z, C) и на телефоне (кнопки на экране, телефон боком).

Разработка: `npm install`, `npm run dev`. Картинки: `python art/build_assets.py`. Подробности — `CLAUDE.md` и `docs/`.
